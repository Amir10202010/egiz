# Производство: что сгенерировать и куда положить

Промты к каждому кадру лежат в [SCENES.md](SCENES.md): у каждой сцены есть **IMAGE PROMPT · START/END** и **VIDEO PROMPT**.
Правила стиля описаны в [ART_DIRECTION.md](ART_DIRECTION.md). Код менять не нужно: сайт сам находит файлы по путям ниже.

## Порядок работы

1. **Картинки.** Для каждой сцены сгенерируйте START, а где указано, ещё и END: 16:9, от 1920×1080.
   Сделайте 4–8 вариантов и выберите лучший. Ко всем промтам добавляйте общий негатив из начала SCENES.md.
2. **Сразу на сайт.** Сохраните START как `NAME.jpg` (ширина 1600 px, качество около 85) по пути из таблицы.
   Сайт сразу покажет этот кадр с медленным наездом камеры, ещё до появления видео.
3. **Видео.** В Flow выберите Gemini Omni Flash 1.2, 16:9, 10 с, режим *Frames to video*: START и END как ингредиенты плюс VIDEO PROMPT.
   Сначала проверьте вариант в 360p, финальный делайте в 720p.
4. **Перекодирование.** Установите ffmpeg (`winget install Gyan.FFmpeg`) и выполните три команды из конца SCENES.md.
   Получатся `NAME.mp4`, `NAME.webm` и `NAME.jpg`.
5. **Файлы в папку.** Положите их в `web/public/media/cinematic/...` по таблице. Видео заменит картинку автоматически.

## Важно

- В интерактивных главах (зонд, перетаскивание Солнца, поле сходства, пределы, планировщик) ролик играет только в начале, затем растворяется в живом 3D. Видео никогда не закрывает то, с чем можно взаимодействовать.
- Пока ролик закрывает экран, 3D-мир не отрисовывается: это экономит GPU.
- Посетителям с «уменьшить движение» или режимом экономии трафика показываются только картинки.
- Каждый кадр подписан «иллюстративный кадр». Не добавляйте в кадры логотипы, флаги, реальные марсоходы и узнаваемых людей.
- Время показа каждой сцены можно поправить в `web/public/media/cinematic/manifest.json`, поле `window`, в единицах глав.
- Глава «Одна почва, две планеты» работает и без видео: это интерактив на реальных данных.
  Глобус цели (Марс или Луна) построен в ортографической проекции, точки на Земле — все оценённые площадки, а таблица сравнивает измеренные значения.
